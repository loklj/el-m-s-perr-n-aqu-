# hito1/

Archivos del **Hito 1** listos para copiar dentro del proyecto Unity.

Unity Hub no crea proyectos en carpetas que ya tienen contenido. Por eso, primero se crea el proyecto en `unity/` con Unity Hub y después se copia esta carpeta encima:

```bash
cp -r hito1/Assets/. unity/Assets/
```

Instrucciones completas: [docs/HITO1_GUIA.md](../docs/HITO1_GUIA.md).

Cuando el proyecto `unity/` exista en el repositorio con estos archivos, esta carpeta se puede borrar.
